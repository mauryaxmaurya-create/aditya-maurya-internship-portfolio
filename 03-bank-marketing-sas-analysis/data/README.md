# Dataset setup

The SAS program uses the UCI Bank Marketing `bank.csv` sample with semicolon-separated values.

The data is not included in this repository. Download the Bank Marketing dataset from the UCI Machine Learning Repository or update the import path in `src/bank_marketing_analysis.sas` to an authorised local copy.

Expected structure:

- 4,521 observations
- 16 candidate predictors
- Binary target column: `y`

Do not commit customer data or any replacement dataset unless its licence and privacy conditions permit public redistribution.
