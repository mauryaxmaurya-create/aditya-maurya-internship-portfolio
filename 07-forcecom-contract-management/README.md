# Force.com Contract Management Prototype

## Overview

This group project designed a Salesforce / Force.com prototype for managing contracts, approvals, vendors, employees and review tasks. The solution demonstrates platform data modelling, role-based access and workflow automation.

## Solution design

The data model contains five core custom objects:

- Employee
- Vendor
- Contract
- Contract Approval
- Review Tasks

Configured automation covered contract approval, review-task assignment and renewal reminders. Custom profiles and permissions separated access for relevant business roles.

## Group project

This prototype was completed as a three-person group project. During the group Zoom sessions, I operated the Salesforce environment and carried out the platform build while the team discussed the implementation decisions together.

For the written report, I completed Section 2, **System Modelling**, including:

- Section 2.1: Data Model for the Contract Management System
- Section 2.2: Custom User Profiles for the Contract Management System
- Employee and Contract Manager profiles
- Organisation-Wide Default access settings
